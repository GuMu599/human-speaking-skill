# 人话写作

> 让中文像一个有判断的人写出来。

人话写作是一套面向中文表达的通用 Agent Skill，不依赖某个单一 AI 产品。它不靠故意口语化、错别字或网络热词制造人味，也不承诺规避任何检测；它做的是在保真的前提下改文字：留下事实、立场和证据强度，删掉空泛套话与模板化结构，再按场景把语气调到恰当的位置。

它适合改写报告、邮件、演讲、社媒内容、产品文案和生成提示词。面对学术或正式材料，它优先守住准确和边界；面对职场、社媒或私密表达，它会让语言更自然、更具体，也更像真实的人会说的话。综合研究原则位于 `reference/integrated-research-principles.md`，用于统一材料门槛、信息账本、段落推进、场景路由和终检标准。

来源展示从简：社交平台只展示平台名称；只引用 skill；GitHub skill 可保留参考链接，其他来源不展示具体链接。安装时优先使用完整 `human-writing-zh/` 目录；WorkBuddy 只是可选平台适配层。

**一句话介绍：** 把“看起来很对”的中文，改成“有人认真说了这句话”的中文。

## 核心特点

- **保真**：不编事实，不夸大结论，不悄悄删掉不确定性。
- **去套话**：清理空泛褒义、名词堆叠、万能连接词和无意义升华。
- **按场景**：区分学术、官方、职场、社媒、口播、私信和产品界面。
- **有分寸**：正式不等于僵硬，亲切不等于轻浮，自然更不等于粗糙。
