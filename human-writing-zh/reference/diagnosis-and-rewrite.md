# 诊断与改写工具箱

## 用最小动作修复，而不是整篇“洗稿”

| 症状 | 常见 AI 式写法 | 更有效的动作 |
|---|---|---|
| 空泛 | “这项工作具有重要意义” | 说清对谁、在哪个环节、带来什么可见变化；无答案就删除 |
| 名词堆叠 | “推进协同机制建设与能力提升” | 还原动作、主体和结果：“把各部门的交接流程定下来” |
| 连接词撑段 | “首先……其次……最后……” | 保留真正有转折的关系，其余直接进入内容 |
| 假力度 | “极大、全面、显著、充分” | 用可验证事实替代；证据不够就降调 |
| 模糊归因 | “专家认为”“业内普遍认为”却无来源 | 有可核查来源就补主体或链接；无来源则改成作者自己的判断，或删掉这层背书 |
| 假平衡 | “不仅……而且……” | 只保留信息量更大的半句，或改成具体递进 |
| 均匀节奏 | 每句都 25 字、每段都三句 | 让重点句短下来，让解释句展开；段落按内容自然收束 |
| 会议纪要腔 | “围绕目标导向，持续推动落地” | 明确谁做什么、为什么现在做、下一步是什么 |
| 替读者想/说教 | “你可能还没意识到”“普通人只要照做就行” | 不替读者预设无知、焦虑或动机；直接说事实、条件和选择 |
| 翻译腔 | “针对这个问题进行一个讨论” | 用中文动词直说：“讨论这个问题”“解决这个问题” |
| 万能结尾 | “未来将继续……共同创造美好未来” | 回到一个具体行动、限制或真实感受；不需要结尾就停下 |

## 动作级信号与材料门槛

不要把单个词当成“AI 指纹”。先看一组修辞动作是否成串出现：先替读者制造一个并不存在的误解，再用“其实/而是”翻案；把三个普通点排成整齐队列；每段开头预告、结尾总结；给抽象名词配抒情动词；用“说实话”“很多人忽略了”表演未经材料支持的真诚。只有聚类信号同时遮住事实或判断时才动手，且优先改动作，不是换一张禁词表。

长篇非虚构还要先过材料门槛：至少能列出支撑主题的事实、数字、动作、原话、流程或可靠来源。材料不够就追问、查证或缩短；同一观点的多次换说法不算段落推进。每个新段落至少增加一项事实、动作、例子、区别或后果，否则删掉或合并。

## 四种改写动作

### 1. 删：去掉不承担信息的句子

原句：

> 本次活动圆满成功，充分展现了团队凝聚力，具有重要意义。

若没有更多事实，改为：

> 活动按计划完成，现场的分工也比上次顺了很多。

若连“分工变顺”也无依据，只写：

> 活动已按计划完成。

### 2. 落地：把标签换成事实、动作或后果

原句：

> 我们持续优化用户体验。

改为：

> 我们把首次上传的三步合成了一步，用户不用再反复选择文件类型。

### 3. 换重心：让真正的判断站到前面

原句：

> 在数字化转型不断深入的背景下，数据治理的重要性日益凸显。

改为：

> 数据越多，口径不统一的问题越难藏。现在最该先解决的，不是再加一张报表，而是把数据定义对齐。

### 4. 调节奏：一句只做一件事

原句：

> 该方案通过整合资源、优化流程、提升效率，为后续工作奠定了坚实基础。

改为：

> 这次先把资源入口收拢了。流程少了两次人工确认，后续接手的人也更容易找到资料。

## 替换时的判断

- “体系、机制、维度、路径、抓手、赋能、闭环”并非禁词。它们在有确定定义的专业语境可以保留；在泛泛句里才要拆开。
- “我认为”也不是人味开关。只有责任、判断或个人经验确实属于说话者时才用。
- 不要把所有转折词删光。真正的因果、让步、对比需要清楚地连接。
- 不必句句追求“金句”。一段自然文字会有普通句，关键是它们不空。
- “具体”只能来自已有材料。没有来源时，不得为了让文章更像人而补数字、经历、场景或情绪。
- **应改**：“你一定不知道，这一步最关键。”没有证据却替读者设定认知；可改为“这一步决定后续能否继续”。**不应改**：教程明确写着“如果你第一次配置，请先完成这一步”，这是必要的前置条件，不是说教。
- **应改**：“很多专家都说这个方案有效。”没有主体、时间或证据；可改为“团队在两次试点后决定继续使用该方案”，前提是原文确有该事实。**不应改**：原文有明确引文、署名或链接时，保留可核查归因，不要为简练把来源删掉。
