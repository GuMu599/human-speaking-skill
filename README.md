# 人话写作

> 把“看起来很对”的中文，写成“有人认真说了这句话”。

有些文字没有错，只是太像一份标准答案。这个 skill 留下事实、判断和分寸，去掉空话、套话和过度工整的结构。

报告、邮件、演讲、社媒文案、产品提示词和界面文字都可以用。该专业时专业，该简短时简短。

## 怎么用

- 通用包：[human-writing-zh-skill.zip](human-writing-zh-skill.zip)
- WorkBuddy：[human-writing-zh-work-buddy.zip](human-writing-zh-work-buddy.zip)
- 其他安装方式：[INSTALLATION.md](INSTALLATION.md)

```text
把这段汇报改得专业一点，但别像公文。保留事实和原来的结论。
```

## 它会做什么

- 轻度润色、人性化改写、深度重写、提示词增强、产品文案。
- 保护事实、数字、专名、链接、引用、限定条件和原有立场。
- 按读者控制解释深度：专业读者看必要信息，新手读者补最小前提。
- 不编造，不模仿特定作者。

完整规则在 [SKILL.md](human-writing-zh/SKILL.md)，专项参考在 [reference](human-writing-zh/reference)。
