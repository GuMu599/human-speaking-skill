# 人话写作

> 把“看起来很对”的中文，写成“有人认真说了这句话”。

有些文字没有错，只是太像一份标准答案。人话写作帮你留下事实、判断和分寸，把空话、套话和过度工整的结构拿掉。

它适合报告、邮件、演讲、社媒文案、产品提示词和界面文字。不是把所有文字改口语，也不替你虚构经历；该专业时专业，该简短时简短。

给它原文和场景即可：

```text
把这段汇报改得专业一点，但别像公文。保留事实和原来的结论。
```

## 一个例子

**改前**

> 为进一步提升系统稳定性，我们计划于 5 月 20 日 22:00 至 24:00 进行支付服务升级，期间相关支付功能将暂停使用，敬请谅解。

**改后**

> 5 月 20 日 22:00—24:00，支付服务升级。期间无法支付。

时间、动作和影响都在；“为进一步提升”“敬请谅解”这类不增加信息的话，删掉了。

## 它会做什么

- 轻度润色、人性化改写、深度重写、提示词增强、产品文案。
- 保护事实、数字、专名、链接、引用、限定条件和原有立场。
- 根据受众决定解释深度：专业读者只看必要信息；新手读者补最小前提。
- 不编造，不模仿特定作者，不承诺检测结果。

完整规则在 [SKILL.md](human-writing-zh/SKILL.md)，专项参考在 [reference](human-writing-zh/reference)。
