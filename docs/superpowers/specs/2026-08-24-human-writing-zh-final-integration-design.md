# 人话写作最终整合版设计

## 目标

把已完成的知乎、微信公众号、小红书、抖音和 GitHub 研究，整理成一个可直接触发的中文写作 skill。skill 吸收可迁移的抽象方法与提示词结构，不复制第三方长段原文，不把检测规避、伪造经历或第三方可识别文风带进默认行为。

## 设计决策

1. `SKILL.md` 只负责触发、模式选择、主流程、优先级和边界。
2. `reference/integrated-research-principles.md` 负责跨平台研究的综合知识库，按材料、结构、表达、场景、学术技术、提示词、评测和排除项组织。
3. 现有 reference 文件保持单一职责；主 skill 按任务路由到最小必要资料，不要求每次加载全部内容。
4. README 明确来源类别、研究数量、代表性链接、许可证状态和吸收边界；逐篇记录保留在 `research/`。
5. 评测检查主 skill 是否调用综合参考，并覆盖保真、场景、来源和反检测边界。

## 非目标

- 不保证任何 AIGC 检测分数，不提供隐藏 AI 使用痕迹的流程。
- 不自动虚构第一人称经历、数据、引文、情绪或人物身份。
- 不模仿在世作者、博主或用户未授权的第三方可识别风格。
- 不把单词禁用表、句长阈值或标点统计当作中文自然度的充分条件。

## 验收标准

- 主 skill 有综合研究路由和明确的保真边界。
- 综合参考覆盖材料门槛、信息账本、段落推进、动作级信号、场景路由、自有样本、正式/学术/技术文本和排除项。
- README 可追溯研究矩阵、代表性来源、许可证与“抽象吸收、不复制原文”声明。
- 全部 PowerShell 评测、`git diff --check` 和 Git 提交通过。
